# RaceDay Event Management System
## Project Description: Briefly explain RaceDay and the problem it solves.
RaceDay is a full-stack, web-based application for organising and participating in running, walking and cycling events
. The app allows organisers to create and manage events.
Participants can join events and track their progress.
